# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately through **GitHub → Security → Report a vulnerability** (a private security advisory). Include steps to reproduce and the affected page or endpoint.

## Supported versions

| Version | Supported |
|---|---|
| 2.x (`main`) | ✅ |
| 1.x (original upload) | ❌ has known critical issues; upgrade |

For the security design and the full list of fixed vulnerabilities, see [docs/SECURITY.md](docs/SECURITY.md).
